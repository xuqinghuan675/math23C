## 结果摘要

- 交易明细共 878,503 行，其中销售 878,042 行、退货 461 行；退货按负数计入后，净销量为 470,975.918 千克。
- 研究时间范围内共有 1,095 个日历日，其中 1,085 天有交易记录；完全无交易的 10 天作为缺失日处理，不直接当作销量为零。
- 商品目录共有 251 个商品，实际出现过销量的商品有 246 个。
- 花叶类累计净销量最高，占全部净销量 42.151%；茄类最低，占 4.763%。
- 各品类日销量均呈右偏和重尾；水生根茎类相对波动最大，花叶类相对稳定。
- 品类关系使用普通秩相关和控制月份、星期、长期趋势后的秩相关进行对照；控制后绝对相关系数达到 0.5 以上的品类对有 5 对。
- 单品关系先排除极少出现的商品，再检查共同出现天数、时间稳定性和阈值变化，避免把偶然关系当成主要结论。

## 数据处理原则

- 销售数量为正、退货数量为负，按日期和商品汇总后得到净销量；
- 有交易记录的日期中，某商品没有流水时按零销量处理；
- 完全没有交易记录的日期保留为缺失日，不纳入主要统计；
- 三层汇总结果相互核对：原始流水、单品汇总和品类汇总的净销量一致；
- 统计关系只表示同步变化，不直接证明因果、互补或替代。

本分析没有复制参考答案的文字、表格和结论，也没有强行使用其他题目的预测或优化方法。
