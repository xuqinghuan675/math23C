# 第一大题运行说明

## 运行顺序

在仓库根目录 `D:\数学建模国赛\math23C` 下执行：

```powershell
python "2023年C题\问题一\脚本\build_q1_panels.py"
python "2023年C题\问题一\脚本\analyze_q1_distribution.py"
python "2023年C题\问题一\脚本\analyze_q1_category_relations.py"
python "2023年C题\问题一\脚本\analyze_q1_item_relations.py"
```

四个程序应按上面的顺序运行：先构造日尺度数据，再进行分布分析、品类关系分析和单品关系分析。

## 输入和输出

- 输入：仓库内 `2023年C题` 目录中的题面、附件 1 和附件 2；
- 结果：`问题一\结果`；
- 图表：`问题一\图表`。

程序不会修改原始附件。运行前需要安装用于读取表格、数值计算、统计分析和绘图的常用 Python 库。

## 复核重点

运行完成后重点检查：

1. 原始流水、单品汇总和品类汇总的净销量是否一致；
2. 完全无交易日期是否仍按缺失日处理；
3. 品类关系和单品关系结果是否生成；
4. 图表是否写入图表目录。
