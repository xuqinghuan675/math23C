# 问题二 v2.1.0 论文指标表

> 用途：论文写作时直接决定“哪些指标放正文、哪些放附录”。本文件不产生新的模型结果，只从 `结果_v2/` 的正式输出中提取和整理指标。

## 1. 指标取舍原则

正文只保留能回答三个问题的指标：

1. **模型预测得准不准**：需求模型 WAPE、成本模型 WAPE；
2. **价格关系能不能用于决策**：价格响应系数及可靠性结论；
3. **最终方案是什么、风险多大**：售价、补货量、预计毛利及联合情景 P10/P50/P90。

其余用于证明稳健性、无泄漏、模型筛选过程的指标放附录，不在正文大面积铺表。

| 辣椒类 | 同星期最近4次均值 | 24.34% | 销量加权成本 + 指数加权移动平均 | 12.62% | -0.0472 | 否 | 22.86% |
| 食用菌 | 同星期最近4次均值 | 27.81% | 固定篮子成本 + 滞后稳健回归 | 5.34% | -0.5636 | 否 | 31.20% |

### 正文怎么解释

- 六类需求最终都选择“同星期最近4次均值”，原因不是模型简单化处理，而是滚动回测和一标准误规则下，复杂模型没有形成稳定、足够大的泛化优势。
- 价格响应只有 **花叶类**通过完整可靠性门槛，因此只有花叶类进行精细价格优化；其他五类采用条件参考加成，避免把不稳定的价格系数硬用于经营决策。
- 花菜、水生根茎、食用菌虽然部分价格系数在统计上呈负向，但端到端预测明显劣化，因此最终不认定为可用于精细定价的可靠关系。

## 4. 正文建议保留的价格关系指标

正文建议只保留：

| 指标 | 是否正文保留 | 理由 |
|---|:---:|---|
| 价格响应系数 | 是 | 直接回答“销量与成本加成定价是什么关系” |
| 是否通过可靠性门槛 | 是 | 决定该系数能否进入最终定价优化 |
| 端到端 WAPE | 是 | 防止只看回归显著性而忽略最终预测效果 |
| 稳健 p 值 / 95% 区间 | 可简写 | 正文文字说明即可，不必六类全铺 |
| 8 个滚动折逐折系数 | 否 | 放附录 |
| 2021/2022 伪未来系数 | 否 | 放附录 |
| bootstrap 负向比例 | 否 | 放附录 |
| 提前一期安慰剂检验 | 否 | 放附录 |
| 固定篮子与销量加权方向一致性 | 否 | 放附录 |
| 价格有效变异 IQR | 否 | 放附录 |
| 历史价格支持等级 | 仅异常时写 | 正文只说明最终价格位于历史支持区间 |

## 5. 正文建议保留的预测指标

正文对需求和成本预测不要同时堆 WAPE、MAE、RMSE、MASE、Pinball Loss、Coverage 等全部指标。

### 正文

- **WAPE**：主误差指标，便于跨品类比较；
- **模型名称**：说明最终为什么选它；
- **P10/P50/P90 或 90% 区间**：只在最终经营策略和风险部分使用。

### 附录

- MAE；
- RMSE；
- MASE / 尺度误差；
- 分位数损失；
- 区间覆盖率；
- 区间平均宽度；
- 逐折 WAPE；
- 一标准误范围；
- 所有候选模型完整排名。

## 7. 论文正文最推荐的表格数量

问题二正文建议控制在 **3–4 张核心表**：

1. 六品类需求/成本/价格关系核心指标表；
