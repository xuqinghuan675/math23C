## 最终结果

v2.1.0 已完成 6000 个联合情景的正式重算、18 项自动测试和最终审计。最终输出为 2023 年 7 月 1 日至 7 日、六个蔬菜品类、共 42 条品类—日期策略。

七天预计毛利：**3160.30 元**。

六品类联合七天毛利情景分位数：

- P10：**1827.57 元**
- P50：**3444.45 元**
- P90：**4198.89 元**

价格关系最终只有 **花叶类** 通过完整可靠性门槛；其余五类采用条件历史参考加成，并继续使用概率需求和成本情景优化补货量。
