# 2023年C题问题二

## 当前结论

问题二已经按照原始四个附件重新审计并重算。主线为：

历史销量规律 → 未来进价和基础需求 → 价格与销量关系 → 稳健定价 → 报童补货。

最终建议不是把网格搜索的最高价格直接当作“最优价”。六个品类的搜索结果都触及正常销售历史上限，说明当前数据只支持“提高价格通常会减少销量”的方向判断，不能支持历史区间内存在一个稳定的内部最优价。因此最终采用正常销售历史中位成本加成，补货量再由损耗率和需求波动决定。

## 最终口径

退货记录保留为负销量并计入净额；折扣记录保留在现实成交和数据审计中，但由于折扣价明显低于同日正常价且多集中在晚间，常规定价模型采用正常销售记录。未来没有给出折扣计划，因此不把历史折扣比例带入未来需求。

品类日售价和日进价均使用销量加权。损耗率直接采用附件四的品类汇总值，只在补货环节修正可销售数量。

需求模型是控制星期和月份的对数需求回归；只有趋势项在滚动回测中至少改善5%才保留。进价只比较近7日均值、近14日均值、指数加权移动平均、同星期中位数和近180日趋势加星期，并逐品类按回测误差选择。
