# 2023年C题问题二

## 当前最终方案

问题二已经基于仓库四个原始附件重新审计并重算。当前正式主线为：

**全量净销量预测基础需求 → 正常销售识别价格响应 → 分层稳健定价 → 损耗修正报童补货。**

核心处理不再走两个极端：

- 不再把 5%~95% / 1%~99% 历史边界上的最高价冒充“内部最优价”；
- 也不再让六个品类全部退化为历史中位加成。

价格关系稳定的 **花叶类、花菜类、水生根茎类、辣椒类**，在正常销售历史 IQR（25%~75%）这一常规经营区间内做局部稳健利润优化；价格关系证据不足的 **茄类、食用菌**，采用正常销售历史中位加成。所有品类的补货量均用随机需求下的易腐品报童模型确定。

本版由 GitHub Actions 直接读取 `2023年C题/附件1~4.xlsx` 重算通过。当前 42 条策略模型预计七天利润合计为 **4301.35 元**。其中 28 条可靠品类策略触及 IQR 上界，这只解释为“典型经营区间内的约束最优”，不宣称无约束全局最优。

## 正式文件

- `最终建模说明.md`：论文主方法、选择理由和表述边界；
- `最终建模说明_分层稳健.md`：自动重算生成的简版说明；
- `结果/七天六品类最终策略_分层稳健.csv`：当前正式 2023-07-01 至 2023-07-07 的 42 条建议；
- `结果/价格关系可靠性_分层稳健.csv`：六品类价格弹性与可靠性分类；
- `结果/基础需求模型回测_分层稳健.csv`、`基础需求模型回测汇总_分层稳健.csv`：全量净销量基础需求回测；
- `结果/策略分解_分层稳健.csv`：典型定价基准与最终方案利润对照；
- `结果/成本预测回测.csv`：五种简单批发价预测方法的滚动七日回测。

原 `求解问题二.py` 和不带 `_分层稳健` 后缀的旧结果保留用于审计和方案演化对照，**不再作为最终论文主结果**。

## 数据口径

- 退货保留为负销量并计入全量净需求；
- 折扣销售计入真实需求规模，但不拿折扣价估计常规价格响应；
- 正常销售记录用于估计售价弹性；
- 品类日售价与进价均按销量加权；
- 损耗率采用附件四品类汇总值；
- 没有库存、缺货、预算、货架容量和箱规数据，因此按品类独立决策并在论文中明确这一边界。

## 复现

在仓库根目录运行：

    python 问题二/脚本/求解问题二_分层稳健.py

该脚本读取 `2023年C题/` 下四个原始附件，并生成当前分层稳健结果。
