# 2023年C题问题二

## 当前正式方案

问题二当前只保留一条正式主线：

**全量净销量预测基础需求 → 正常销售识别价格响应 → 分层稳健定价 → 损耗修正报童补货。**

- 花叶类、花菜类、水生根茎类、辣椒类：价格关系稳定，在正常销售历史 IQR（25%~75%）内做局部稳健利润优化；
- 茄类、食用菌：价格关系证据不足，采用正常销售历史中位加成；
- 六个品类均使用随机需求下的易腐品报童模型确定每日补货量。

2023-07-01 至 2023-07-07 共 42 条正式策略，模型预计七天利润合计为 **4301.35 元**。其中 28 条可优化策略触及 IQR 上界，因此只解释为“历史常规经营区间内的约束最优”，不宣称无约束全局最优。

`结果/` 仅保留以下文件：

- `价格关系可靠性_分层稳健.csv`：价格弹性与可靠性分类；

- `基础需求模型回测汇总_分层稳健.csv`：基础需求回测汇总；
- `策略分解_分层稳健.csv`：参考策略与最终策略利润分解；
- `成本预测回测.csv`：批发价预测方法滚动回测。

## 数据口径

- 退货保留为负销量并计入全量净需求；
- 折扣销售计入真实需求规模，但折扣价不用于常规价格响应估计；
- 品类日售价与进价按销量加权；
- 损耗率采用附件四品类汇总值；
- 附件没有库存、缺货、预算、货架容量和箱规数据，因此按品类独立决策，并在论文中明确这一边界。
