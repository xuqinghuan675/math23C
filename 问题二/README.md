## 方法概括

保留真实销售、折扣和退货记录；退货按负销量计入净额。品类日售价和日进价均按销售量加权。成本只比较三种简单预测方法，用滚动七日回测选取品类内表现较好的方法。需求采用不含未来未知折扣比例的对数线性模型，使用对数尺度残差抽样并做反变换修正。最后在历史加成率区间内进行价格网格搜索，用易腐品报童模型确定补货量。

## 复现命令

在 math23C 仓库根目录执行：

    python 问题二/脚本/求解问题二.py

脚本只读取 2023年C题/ 下的四个原始附件，并把结果写入 问题二/结果/ 和 问题二/图表/。

## 重要解释

主方案中的预计利润是模型估计，不是已发生利润。若价格触及历史上限，应结合 价格边界敏感性.csv 一起写入论文，说明该结果受经营边界约束。
