# 2023年C题问题二

## 当前正式方案

问题二当前只保留一条正式主线：

**全量净销量预测基础需求 → 正常销售滚动选择价格响应 → 七日批发价路径预测 → 同星期局部定价 → 损耗修正报童补货。**

当前价格响应不再直接使用常弹性对数—对数模型做利润寻优。原因是当估计的价格弹性绝对值小于 1 时，常弹性利润函数会系统性偏向更高价格，容易把解机械推到人为价格边界。

正式价格响应层同时比较：

- 半对数售价：`log(D)=...+bP`；
- 半对数加成：`log(D)=...+bm`，其中 `m=P/C-1`；
- 对数—对数售价：`log(D)=...+b log(P)`，仅作为滚动预测基准，不直接参与利润寻优。

每种模型均比较是否加入时间趋势，并用滚动 7 日回测选择。只有可用于定价的半对数模型同时满足以下条件，才允许进入利润优化：

1. 全样本价格系数为负；
2. Newey-West/HAC 稳健 `p<0.05`；
3. 至少 7/8 个滚动回测折价格系数为负；
4. 样本外 WAPE 不得明显劣于三种函数中的最佳模型。

若不满足，则不输出伪精确的“最优价格”，而采用最近一年同星期条件中位成本加成。

| 花菜类 | 半对数售价 | -1.1185 | 是 | 局部稳健利润优化 |

| 茄类 | 半对数加成 | -0.0691 | 否 | 同星期条件中位加成 |
| 辣椒类 | 半对数售价 | -0.4540 | 否 | 同星期条件中位加成 |
| 食用菌 | 半对数售价 | -0.2348 | 否 | 同星期条件中位加成 |

辣椒类虽然价格系数显著为负，但半对数售价的滚动 WAPE 为 0.3418，明显劣于对数—对数基准的 0.3104，因此不强行用于定价优化。

水生根茎类由数据自动选择为半对数加成模型：其滚动 WAPE 为 0.5117，优于半对数售价的 0.5179 和对数—对数的 0.5246，同时价格系数显著且 8/8 回测折均为负。

## 批发价预测

批发价预测同时比较水平方法与动态七日路径方法。滚动回测不仅评价价格水平 WAPE，也评价逐日变化路径误差；动态模型只有在价格水平误差没有明显恶化时才有资格入选。

当前入选模型：

- 水生根茎类：近 7 日均值；
- 花叶类：指数加权移动平均 + 近周形状收缩（rho=0.30）；
- 花菜类：指数加权移动平均；
- 茄类：近 14 日均值；
- 辣椒类：指数加权移动平均；
- 食用菌：近 14 日均值。

## 补货模型

六个品类均继续使用随机需求下的易腐品报童模型。给定损耗率 `L`、预测批发价 `C` 和售价 `P`：

```text
有效单位成本 C_eff = C / (1-L)
临界分位数 CR = 1 - C_eff / P
```

从当日经价格响应修正后的随机需求样本中取 `CR` 分位数作为计划可销售量，再除以 `1-L` 得补货量。补货保留 0.1 kg 粒度。

- 退货保留为负销量并计入全量净需求；
- 折扣销售计入真实需求规模，但折扣价不用于常规价格响应估计；
- 品类日售价与进价按销量加权；
- 损耗率采用附件四品类汇总值；
- 附件没有库存、缺货、预算、货架容量和箱规数据，因此按品类独立决策；
