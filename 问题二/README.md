# 2023年C题问题二

## 当前正式方案

问题二当前只保留一条正式主线：

**全量净销量预测基础需求 → 正常销售识别价格响应 → 七日批发价路径预测 → 同星期局部定价 → 损耗修正报童补货。**

核心原则：

- 花叶类、花菜类、水生根茎类、辣椒类：价格关系稳定，使用正常销售价格弹性做逐日局部利润优化；
- 茄类、食用菌：价格关系证据不足，不给出伪精确最优价，采用同星期条件中位成本加成；
- 定价不再把七天复制成同一加成率。每一天根据最近一年同星期正常销售加成率构造中央经营带，并向全局分布收缩；
- 可靠品类只在该日 **35%~65% 分位中央经营带**内优化，避免用极端历史边界抬高利润；
- 六个品类均使用随机需求下的易腐品报童模型确定每日补货量。

2023-07-01 至 2023-07-07 共 42 条正式策略，模型预计七天利润合计为 **4552.95 元**。可靠品类的 28 条局部优化策略仍触及各自中央经营带上界，因此结果只解释为“有历史经营支持的局部约束最优”，不宣称无约束全局最优。

### 七天建议售价范围

- 水生根茎类：**19.35~19.47 元/kg**
- 花叶类：**5.85~5.99 元/kg**
- 花菜类：**12.88~13.12 元/kg**
- 茄类：**7.20~7.37 元/kg**
- 辣椒类：**6.46~6.56 元/kg**
- 食用菌：**5.92~5.98 元/kg**

因此当前结果是真正的逐日价格策略，而不是同一品类七天复制一个价格。

## 批发价预测

批发价预测同时比较水平方法与动态七日路径方法。滚动回测不仅评价价格水平 WAPE，也评价逐日变化路径误差；动态模型只有在水平预测误差没有明显恶化时才有资格入选。

当前入选模型：

- 水生根茎类：近 7 日均值；
- 花叶类：指数加权移动平均 + 近周形状收缩（rho=0.30）；
- 花菜类：指数加权移动平均；
- 茄类：近 14 日均值；
- 辣椒类：指数加权移动平均；
- 食用菌：近 14 日均值。

只有花叶类的动态成本路径在滚动回测中真正胜出，其余品类保留水平成本预测，避免为了“价格每天不同”而人为制造成本波动。

- 退货保留为负销量并计入全量净需求；
- 折扣销售计入真实需求规模，但折扣价不用于常规价格响应估计；

- 损耗率采用附件四品类汇总值；
