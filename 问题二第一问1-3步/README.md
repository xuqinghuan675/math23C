# 问题二第一问：Step1–6 完整说明

## 当前状态

问题二第一问的一至六步已经完成：

1. 清洗销售流水、关联商品分类和批发价格；
2. 按品类和日期构造日面板，并整理月份、星期特征；
3. 绘制价格与销量的探索性散点图；
4. 以统一的对数—对数多元回归作为主模型，线性多元回归作为对照；
5. 检验售价效应，并检查残差自相关、异方差、正态性和时间趋势；
6. 生成主模型的拟合值、残差图、价格弹性图和局部价格反推结果。

## 本阶段统一口径

第四至第六步严格沿用前面交接的面板数据：退货和打折销售已经在一至三步中排除，日平均售价采用销售额加权平均，月份和星期作为控制变量。这里的售价是品类日平均售价，不是单个商品的单独定价。

## 正式模型说明

本阶段统一采用对数—对数多元回归作为价格—销量关系的主模型，控制月份和星期；线性多元回归保留为对照，另增加时间趋势敏感性分析。价格系数解释为价格弹性。

| 品类 | 主模型价格弹性 | 售价效应结论 |
|---|---|---|
| 花叶类 | −0.7951 | 通过多重检验校正 |
| 花菜类 | −1.0673 | 通过多重检验校正 |
| 水生根茎类 | −0.6156 | 通过多重检验校正 |
| 茄类 | −0.4030 | 通过多重检验校正 |
| 辣椒类 | −0.6346 | 通过多重检验校正 |
| 食用菌 | −0.1683 | 未通过多重检验校正 |

主模型的价格系数表示价格上涨1%时销量的平均百分比变化。线性模型和时间趋势敏感性模型用于检查主模型结论的稳定性，不用于替代主模型的弹性解释。

## 结果怎么解释

- 六个品类的售价效应估计值均为负；
- 其中五个品类通过稳健显著性和多重检验校正；
- 食用菌的售价效应证据不足，不能写成确定的显著影响；
- 六个品类的残差都存在明显自相关和异方差，所以使用稳健标准误；
- 当前模型是价格—销量关系的基础统计模型，不是最终的定价优化或补货决策模型，也不能单独证明因果关系。

## 销量增加一千克时的价格反推

当前需求模型可以在各品类的平均价格和平均销量附近，给出“销量增加一千克对应的局部价格变化”。这是一种逆需求关系的局部敏感度，不等同于成本加成定价。详细数值见 `output/step4_6_log_primary/销量增加1千克的局部价格变化.csv`。

成本加成定价还需要单位批发成本、损耗率和目标加成率；这些因素没有被当前第一问的价格—销量回归直接估计。

## 分时段对比图

六个品类各生成一张多面板图，面板统一包含：整体关系、月份、季度、季节、逐日趋势、节假日与非节假日、季节销量—售价表、关键指标汇总表。

- 所有面板固定使用同一套度量：日总销量（千克）和销售额加权的日平均售价（元/千克）；
- 月份、季度、季节和节假日面板使用分组平均值；
- 日期面板使用逐日销量和逐日售价，并叠加销量七日移动平均；
- 季节划分固定为：春季（3—5月）、夏季（6—8月）、秋季（9—11月）、冬季（12—2月）；
- 六个品类同类面板使用统一刻度，保证品类之间可以直接比较。

图表目录为 `output/分组对比图/`，统计表为 `output/分组统计汇总.csv`，绘图脚本为 `分时段对比图.py`。
