# 问题二第一问：Step1–6 完整说明

## 当前状态

问题二第一问的一至六步已经完成：

1. 清洗销售流水、关联商品分类和批发价格；
2. 按品类和日期构造日面板，并整理月份、星期特征；
3. 绘制价格与销量的探索性散点图；
4. 对六个品类分别建立线性模型和对数模型；
5. 检验售价效应，并检查残差自相关、异方差、正态性和时间趋势；
6. 选择验证误差较小的模型，生成拟合值、残差图和价格效应图。

## 本阶段统一口径

第四至第六步严格沿用前面交接的面板数据：退货和打折销售已经在一至三步中排除，日平均售价采用销售额加权平均，月份和星期作为控制变量。这里的售价是品类日平均售价，不是单个商品的单独定价。

## 模型不是全部使用对数

交接说明要求线性模型和对数模型都运行后再比较，并没有要求六个品类全部使用对数模型。当前选择结果如下：

| 品类 | 选择模型 | 售价效应结论 |
|---|---|---|
| 花叶类 | 线性模型 | 通过多重检验校正 |
| 花菜类 | 线性模型 | 通过多重检验校正 |
| 水生根茎类 | 线性模型 | 未通过稳健检验 |
| 茄类 | 对数模型 | 通过多重检验校正 |
| 辣椒类 | 对数模型 | 通过多重检验校正 |
| 食用菌 | 线性模型 | 未通过稳健检验 |

选择依据是按时间顺序保留前80%的日期建模，用后20%的日期比较原始销量预测误差。这样避免把不同响应尺度下的决定系数直接比较。

## 结果怎么解释

- 六个品类的售价效应估计值均为负；
- 其中四个品类通过稳健显著性和多重检验校正；
- 水生根茎类和食用菌的售价效应证据不足，不能写成确定的显著影响；
- 六个品类的残差都存在明显自相关和异方差，所以使用稳健标准误；
- 当前模型是价格—销量关系的基础统计模型，不是最终的定价优化或补货决策模型，也不能单独证明因果关系。
